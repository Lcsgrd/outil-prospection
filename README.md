# Outil de prospection

Recherche d'entreprises par département, ville et métier (code APE), à partir du registre officiel des entreprises, avec complément gratuit des coordonnées via OpenStreetMap.

**Utiliser l'outil :** https://lcsgrd.github.io/outil-prospection/

- `index.html` : l'outil (fonctionne dans le navigateur, aucune installation).
- `enrichissement_emails.gs` : script Google Sheets qui cherche les emails sur les sites web des entreprises (aussi copiable depuis le mode d'emploi de l'outil).

Sources : [recherche-entreprises.api.gouv.fr](https://recherche-entreprises.api.gouv.fr), [geo.api.gouv.fr](https://geo.api.gouv.fr), [OpenStreetMap](https://www.openstreetmap.org) (Overpass API).
